旅行护照 · 第三版到访记忆原型

打开方式
工程化后的运行与开发命令见项目 README.md。
离线文件：dist/standalone/旅行护照.html；历史原型保留在 artifacts/legacy/。
页面源码：src/views/；交互逻辑：src/controllers/；存储：src/storage/；样式：src/styles/。
生成单文件：npm run build:standalone。

设计依据
本版以当前对话的全国数字文化旅行护照为唯一项目依据。
白色用于承托作品与阅读；炭黑建立信息层级；蓝色用于主要操作与选中状态。
纪念章使用独立配色，图案对应器物、建筑、山水与当代艺术。
墨绿、米白、朱红的第一版界面配色未沿用。
桌面左栏属于原型评审界面，手机端只呈现产品界面。

可体验的流程
我的护照、章册与时间轴、想去收藏、搜索与类别/城市筛选、场馆详情、位置指引、
现场扫码/碰一碰/票根领取、领取成功与重复领取、放大章面、按馆记录感想和照片、旅行卡预览与 PNG 下载。
首次使用体验与已有收藏互相独立，切换不会清除原有记录。

第三版：到访记忆
首页为“足迹／章册／想去”，默认展示足迹。一次到访以“场馆＋参观日期”归档。
足迹卡片将票根、纪念章与简短感想放在同一画面；到访详情集中保存完整票根、关联徽章、照片和感想。
同一场馆、同一天可以包含多张票根与多枚纪念章，到访次数保持为一次。
可以从章册中的徽章跳回对应到访，也可以从到访页查看关联徽章。
确认页默认勾选保存票根；原图保存在当前浏览器的 IndexedDB 中，保持导入文件原始内容，不会上传。
可以仅保存票根与到访，也可以选择“其他场馆”手动填写名称、城市及展览，不要求先领取徽章。
票根原图可放大查看，并可单独移除；移除后保留到访、徽章、照片、感想与去重记录。
每次到访拥有独立的照片和感想，同馆不同日期互不覆盖。
分享默认不包含票根、照片和感想；主动带上票根时，可选择一张票根，手动裁剪或用不透明区域遮挡信息。
分享编辑仅生成临时副本，保留原图；可撤销、还原，确认后加入预览及下载的分享卡。
第三版使用独立的本地元数据键，并兼容读取第二版记录；不会覆盖旧版存储。
离线文件内置演示内容，用户私人记录与导入的票根保存在浏览器中。

票根领取更新
首页右上角“票根补领”可直接进入；盖章页三个并列入口为“现场扫码／碰一碰／票根领取”。
支持拍摄/相册选择 JPG、PNG、WebP 图片，以及无需图片的示例票根体验。
原图可选择保存在本机护照中，不会上传；原型使用示例结果，不运行真实 OCR。
确认页使用明确标注的示例结果，用户可校正场馆和参观日期，按日期选择匹配的馆章/特展章。
示例票根为2025年10月18日的临江博物馆参观票，对应馆章和一枚2025年历史特展纪念章。
两枚章使用同一主题插画，特展版本以年份标签和独立标题区分。
时间轴按参观日期、场馆合并展示，一次到访获得多枚章计为一次到访。
印章详情独立显示参观日期、首次领取日期和领取方式；补录不改动已有首次领取日期或私人记忆。
同一章允许保留多次到访，用户可切换到访日期，旅行卡使用当前选中的参观日期。
重复示例票根/完全相同的图片内容可识别已有领取记录，支持补领剩余章，不重复增加到访次数。
图片去重仅是原型中的本地演示规则，不代表真实票号验证或票根真实性核验。
保留旧版浏览器记录，新增字段按需兼容；未接入真实票根核验或账户服务。

演示边界
所有场馆、章面与开放信息均为虚构概念内容，生成的建筑图片不代表任何真实场馆。
现场扫码/NFC领取为模拟；拍摄票根按钮会打开设备提供的图片/相机选择器，未连接真实到访验证、用户账号或场馆服务。
第三版元数据保存在 cultural-passport-prototype-v3，兼容读取本产品 cultural-passport-prototype-v2 的旧记录。
票根原图保存在本机 IndexedDB cultural-passport-memory-v3，不会读取其他项目的数据。
照片和感想不会上传；分享内容须由用户勾选，PNG 文件由浏览器在本地生成。
“展览纪念章”在本版仅呈现藏品类型，未实现真实活动上下架和授权管理。

体验与视觉修订
底色曾试过暖白纸色与暖灰分区，已撤回：保持白色底与冷灰分区。
日期与统计数字使用内嵌的等高数字子集字体，其余文字仍为系统字体；数字 0 不再与字母 o 混淆。
英文眉题只保留在护照首页与分享卡；产品界面的可读文字不小于 12px，票面图样、分享卡预览、英文装饰标签、章面年份标签与纪念章编号除外。
足迹与入册成功页的拼贴中，票根日期移到左侧，不再被纪念章遮挡。
未收藏的章在详情页以灰度章面和“尚未收藏”标识呈现，页头标题为“纪念章”；收藏后恢复全彩。
到访页的页脚固定为分享；到访页与章详情页的页头不再重复分享入口；感想与照片在“留住当时的心情”分区内填写。
没有实景图的场馆页沿用原来的头图：纪念章居中，背后衬场馆关键词大字（曾试过虚化色域方案，已撤回）。
特展章沿用馆章插画，以古铜色章面与年份标签区分；下载的分享卡使用同样的处理。
章详情页的放大层改为可把玩的章面：拖动倾斜并带流动高光，松手回弹；已收藏的章可翻到背面，查看刻着的场馆、到访日期与编号。
未收藏的章只能小幅倾斜、不能翻面；系统开启“减少动态效果”时章面保持静止，仍可用按钮翻面。章面为 CSS 透视效果，未引入 3D 库。
足迹改为轻量时间线：细轴与圆点位于页边距内，日期移到节点旁并放大；按年份分段。
有票根或照片的到访保留整页卡片；只有纪念章或仅有记录的到访收成一行，显示章面、场馆、展览与一句感想。
发现页的目的地列表保持单列；为每个场馆补齐实景图后再改为双排图片卡。
每枚已收藏的章有一个收藏编号（No. 加六位数字），在领取时写入记录并保持不变；旧记录在读取时补齐。
编号出现在盖章成功页、票根入册成功页、章册、到访页的纪念卡、章详情页的到访印记，以及章背面的中心；原有的纪念章型号（如 LJ-A-0002）刻在章背面的边缘，并列在到访印记中。
收藏编号由本机按章与领取日期模拟生成，领取越晚数字越大，仅用于演示收藏感；它不是真实的发行序号，不保证跨设备唯一。
展览纪念章为限量发行：编号写作“No. 序号 / 发行量”，章详情页显示发行进度与剩余数量，票根确认页与场馆页标出“限量”。常设馆章不限量。
旅行卡预览与下载的图片在每枚章的名称下带上收藏编号。
发行量（柔软的秩序 8000 枚、器物与时间·2025 10000 枚）与发行进度均为本机模拟的演示数据；发完后的处理规则尚未设计。
领取成功改为一段“落章”仪式：空印位 → 章从上方压下并回弹 → 落点扩散一圈 → 编号逐位滚到位 → 高光扫过章面，文字依次出现；安卓设备在落章瞬间短震。
票根入册时票根先滑入，纪念章逐枚盖在票根上，编号逐个揭晓。重复到访或没有新章时只播放落章，不滚动编号。
仪式只在领取后播放一次，点击页面任意位置可立即结束；系统开启“减少动态效果”时直接显示结果。不使用声音与彩带。
现场领取的成功页上，章本身就是可把玩的章面：横向拖动或轻点翻面，纵向滑动仍然滚动页面，不再弹出查看层。页面只保留标题、章、章名、编号与“翻到背面”，场馆与日期在章的背面。
票根入册的成功页上章盖在票根上，点击编号行打开章面查看层。
演示护照默认带有一次 2025.10.10 的临江博物馆到访：一张示例票根和特展章“器物与时间·2025”，用来呈现限时、限量的纪念章；足迹因此分为 2026 与 2025 两段。
票根入册流程的示例票根是另一天（2025.10.18）：入册后新增一次到访和馆章“青铜回响”，特展章沿用原有的收藏编号并记为第二次到访。首次使用状态下仍为一次领取两枚。
离线单文件修正：纪念章插画内联后约 3.7 MB，超过浏览器对 CSS 自定义属性的长度上限，章面在离线文件中不显示。现在改为运行时转成 blob 地址再交给样式表；网站版不受影响。
足迹卡片在拼贴下方逐枚列出纪念章：章名、“特展”或“限量”标识、收藏编号。
足迹与章册各有一个“分享”入口（标签栏右侧），生成一张总览旅行卡：足迹卡按年份列出到访日期、场馆、城市与章面；章册卡列出章面、章名与收藏编号。
总览卡不包含票根、照片与感想，也没有可勾选项；到访超过 10 次或章超过 12 枚时只列出最近的，并注明其余数量。
